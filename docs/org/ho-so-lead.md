# Hồ sơ Lead

Lead là người duy nhất GDM trao đổi, người ra đầu bài và duyệt. Mọi file luật của phòng chỉ ghi "Lead" và đọc giá trị ở bảng này. Thói quen làm việc chi tiết: `docs/knowledge/95-cach-lead-lam-viec.md`.

| Khóa | Giá trị |
|---|---|
| Tên | Huy |
| Vai trò | Game Designer |
| Studio | DATN-SP27 (indie) |
| Ngôn ngữ tài liệu và trả lời | Tiếng Việt có dấu, thuật ngữ kỹ thuật giữ tiếng Anh |
| Cấm emoji | Có |
| Cấm gạch dài (chỉ dùng "-") | Có |
| Cấm dấu chấm phẩy | Có |
| Bộ vai | 10 vai theo hệ thống: story, character, combat, items, world, quan, economy, ux, tech, qa |
| Nơi viết GDD | Google Sheet GDD của game theo khuôn `docs/process/templates/gdd-sheet-khuon-indie.md` (nguồn chuẩn), GDD hệ thống viết markdown trong repo |
| Game đầu tiên | Space Salvage (tên tạm), indie 2D action exploration + quản lý quán, Unity PC, link Sheet GDD trong CLAUDE.md |

Văn phong bật ở bảng trên áp cho mọi chỗ người dùng nhìn thấy: báo cáo, GDD, Sheet, label câu hỏi. Đổi giá trị ở đây, không sửa từng file luật.
