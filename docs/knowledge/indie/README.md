# Kho tri thức thiết kế game indie

Kiến thức chuyên môn cho phòng Game Designer khi làm Space Salvage. Khác với playbook (`docs/playbooks/indie/`, cách làm việc), kho này là kiến thức nền: thuật ngữ, nguyên lý, con số có nguồn, phân tích game tham chiếu. Kho cũ `docs/knowledge/*.md` rút từ Puzzle mobile, chỉ để tra phương pháp.

## Ai đọc gì

| File | Nội dung | Vai đọc |
|---|---|---|
| `00-nen-tang-thiet-ke.md` | MDA, pillar, core loop và meta loop, động lực người chơi, flow, risk và reward, game feel, phạm vi MVP, playtest | Mọi vai |
| `05-game-tham-chieu.md` | Phân tích game cùng cấu trúc hai vòng (Dave the Diver, Moonlighter, Stardew Valley...) | Mọi vai |
| `10-narrative.md` | Cốt truyện, kể chuyện trong game vòng lặp, lời thoại | gd-story |
| `15-character.md` | Nhân vật chính, điều khiển, NPC, thiết kế nhân vật pixel art | gd-character |
| `20-combat.md` | Combat, quái, hit feel | gd-combat |
| `25-items-crafting.md` | Vũ khí, vật phẩm, chế tạo | gd-items |
| `30-world-level.md` | Map, môi trường, level design, nhịp chuyến | gd-world |
| `35-management-sim.md` | Quản lý quán, hàng đợi, khách | gd-quan |
| `40-economy-progression.md` | Economy, tiến độ, đường cong | gd-economy |
| `45-ux-ui.md` | HUD, UI, onboarding PC | gd-ux |
| `50-technical-design.md` | Data-driven design, sim, pipeline Unity | gd-tech |
| `55-qa-playtest.md` | QA thiết kế, playtest, đo lường | gd-qa |

## Luật của kho
- Mỗi nguyên lý và con số trỏ tới nguồn có link đã kiểm. Không có nguồn thì không ghi.
- Vai giữ file sửa file của mình. Bài học mới từ dự án ghi vào file của vai và báo GDM qua `/retro`.
- Brief tạo kho: `production/briefs/2026-11-19-kho-tri-thuc-indie.md`.
